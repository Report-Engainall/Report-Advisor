# Report-Advisor

[![Open in Bolt](https://bolt.new/static/open-in-bolt.svg)](https://bolt.new/~/sb1-6zubls7a)

Report-Advisor is a tenant-safe, evidence-first document and business intelligence application.

## Current execution state

The A0 Document & Data Intelligence Engine is complete at the contract/gate level, including schema discovery hardening, entity reconciliation, review/quarantine, governed transactional routing, Onyx canonical adaptation, and golden-dataset quality gates. Downstream phases focus on trusted report execution, entitlements, decision automation, advanced intelligence, and production SaaS certification.

## Non-negotiable safety principles

- No silent source-field loss.
- No cross-tenant data access.
- No high-impact automation without explicit evidence and policy gates.
- No transaction commit from review/quarantine state.
- No replenishment recommendation that violates protected liquidity.
- No hidden fixed demand horizon; horizons are explicit runtime/report inputs.
