# UI Reference Inspiration

This directory is reserved for user-provided visual references for the Report-Advisor UI/UX redesign.

## Purpose

- Color palettes and visual direction
- Layout and navigation inspiration
- Dashboard references
- Cards, tables, charts, and interaction patterns
- Arabic RTL visual references

## Rule

These images are **reference material only**. They are not application assets and must not be imported into production UI automatically.

The implementation team should study the references and translate the useful visual principles into the Report-Advisor design system while preserving the project's real data, engines, evidence chain, Auth/RLS, and existing functionality.

## Uploading references

Add image files directly to this directory from the GitHub web interface. Prefer compressed JPG/PNG/WebP files and avoid unnecessary duplicates or very large originals to preserve repository space.
