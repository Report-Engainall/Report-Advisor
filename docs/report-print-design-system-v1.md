# Report Print Design System v1

Canonical print requirements:
- cover and report identity
- section hierarchy
- page header/footer and page numbers
- report ID, Data As Of, generated timestamp
- repeated table headers
- safe page breaks
- grayscale-safe status/priority markers
- evidence references
- approval and acknowledgement areas where required

Print output must be a deterministic projection of the canonical Report Intelligence Model. It must not calculate business truth independently.
