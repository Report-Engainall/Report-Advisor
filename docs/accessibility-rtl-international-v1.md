# Accessibility / RTL / International UX v1

Acceptance baseline for new W2 surfaces:
- Arabic RTL is the primary layout mode.
- English LTR must not reverse numeric meaning or table relationships.
- Keyboard navigation reaches every actionable control.
- Visible focus state is mandatory.
- Interactive controls have accessible names.
- Tables preserve header association and horizontal navigation.
- Responsive layouts work on mobile widths without hidden critical actions.
- Contrast is not conveyed by color alone.
- Numbers, dates, currencies and timezones are formatted from explicit locale/context.
- Status, priority and risk always have text/icon semantics in addition to visual treatment.
- Loading, empty and error states are explicit and non-destructive.

No new feature is COMPLETE from a UX perspective until these checks are covered by its applicable UI/runtime evidence.
