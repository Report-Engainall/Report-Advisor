# مرجع واجهات الأغبري — Visual Product Target

هذا المجلد هو المرجع الرسمي لتحويل Report-Advisor إلى واجهة:

**الأغبري — ذكاء الأعمال والقرار**

## المرجع البصري
المرجع الأصلي في مكتبة المشروع هو الملف:

**لوحة ذكاء الأعمال بالأغبري.png**

المرجع يحدد التكوين العام وليس مجرد الإلهام:
- RTL عربي أصيل.
- Sidebar أيمن داكن وهوية الأغبري.
- Top bar للبحث والفترة والتنبيهات والحساب.
- Dashboard تنفيذية مع KPI ورسوم وحركة ومستندات وتنبيهات وقرارات.
- مركز العمل.
- تحليل المستندات والبيانات مع المعاينة وحالات الثقة والتحقق.
- التقارير التنفيذية.
- المخزون والتحصيل والربحية.
- مركز المساعد الذكي وDecision Intelligence.
- إدارة العملاء والمنتجات.
- إعداد النظام.
- Responsive/mobile.

## قاعدة التنفيذ
الواجهة الجديدة هي طبقة فوق مصادر البيانات والـEvidence الموجودة. يمنع:
- اختلاق أرقام أو حالات.
- إنشاء Mockup منفصل عن المنتج.
- إزالة provenance/evidence.
- استبدال المسارات الكانونية بمسارات بديلة لمجرد التجميل.
- إعادة بناء محركات الأعمال التي تعمل أصلًا.

## نطاق العمل الحالي
الفرع ui/aghbari-visual-target-20260921 يبدأ من main الحالي ويحوّل نظام التصميم المشترك أولًا، ثم يطبّق المطابقة على الصفحات الحرجة، ثم بقية المسارات عبر نفس المكونات المشتركة.

## معيار القبول
كل شاشة تجارية يجب أن تتبع:
**الأغبري visual system → بيانات حقيقية → حالة ثقة واضحة → drill-down/evidence → إجراء أو قرار عند توفره.**
