# PRODUCT VALUE GATE — REPORT-ADVISOR
## 2026-10-02

Every major capability crosses the following gates before being called product-complete.

### A — Truth
`REAL SOURCE → CANONICAL TRUTH → DATA QUALITY STATE`

No invented facts.

### B — Intelligence
`WHAT → WHY → SO WHAT → WHAT NEXT`

Every material statement is explicitly classified:
`OBSERVED | DERIVED | INFERRED | RECOMMENDED`

Unsupported causality remains a hypothesis.

### C — Evidence
Every material claim retains:
`TENANT + SOURCE HASH + IMPORT JOB + EVIDENCE SNAPSHOT/PASSPORT`

Cross-tenant/source/snapshot/job/hash access must fail closed.

### D — Action
`RECOMMENDATION → DECISION → APPROVAL → WORK`

Each state is distinct. A recommendation is not a decision; a decision is not approval; approval is not execution.

### E — Outcome
`WORK → OBSERVED OUTCOME → READBACK`

Expected and actual outcome are separate. Missing actual evidence is `INSUFFICIENT`, never success.

### F — UX
The user can traverse:
`WHAT → WHY → PROOF → WHAT NEXT`

Loading, empty, error, retry, permission, review-required and blocked states are explicit.

### G — Export
Decision Packet reproduces the same conclusion, evidence lineage and action-chain state. Raw/data export remains a separate mode.

### H — Learning
Outcome preserves:
`ARCHETYPE_ID + PROFILE_VERSION + RULE_ID/RECOMMENDATION_ID`

Future profiles may evolve without rewriting historical results.

### Close rule
Build, CI, route rendering or HTTP 200 alone never closes a capability. Close requires the relevant real-source journey, persistence, evidence, readback, and browser/runtime proof.
